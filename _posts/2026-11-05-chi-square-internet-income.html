--- layout: post title: "Is internet use linked to a country's income group? A chi-square test with Bonferroni follow-ups" date: 2026-11-05 09:10:00 +0500 ---

This is the second post in a small series on the Gapminder country data from the Data Analysis Tools course (213 countries, one row per country). The first post compared life expectancy across income groups. This one asks whether income group is related to how widely the internet is used.

Question and variables

Question: is the chance that a country has high internet use different between low, middle and high income countries?

  • Response (made binary): internetuserate, internet users per 100 people. I split countries at the median: "high" means above the median of 29.0 per 100, "not high" means at or below it.
  • Explanatory (categorical, 3 levels): income group, made by cutting incomeperperson into tertiles: low, middle, high.

Hypotheses. H0: income group and high internet use are independent (the share of high-internet countries is the same in all three groups). H1: they are not independent. Significance level: 0.05.

Load and prepare the data

I keep the 173 countries that have all four series variables (income, life expectancy, internet use, urbanization), the same sample as in the other posts. The file is the Gapminder course file as hosted in the public GitHub repository raffg/Coursera-Data-Analysis-and-Interpretation.

import pandas as pd
import matplotlib
matplotlib.use("Agg")
import matplotlib.pyplot as plt
import scipy.stats as stats
from itertools import combinations

data = pd.read_csv("data/gapminder.csv", na_values=" ")
cols = ["incomeperperson", "lifeexpectancy", "internetuserate", "urbanrate"]
data[cols] = data[cols].apply(pd.to_numeric, errors="coerce")
sub = data.dropna(subset=cols).copy()
print("countries with all four variables:", len(sub))

sub["income_group"] = pd.qcut(sub["incomeperperson"], 3, labels=["low", "middle", "high"])
median_net = sub["internetuserate"].median()
sub["high_internet"] = (sub["internetuserate"] > median_net).astype(int)
print("median internet use rate:", round(median_net, 2), "per 100 people")
print(sub["high_internet"].value_counts().sort_index())

The chi-square test of independence

chi2, p, dof, expected = stats.chi2_contingency(counts)
print("chi-square =", round(chi2, 2), " df =", dof, " p =", p)
print(pd.DataFrame(expected, index=counts.index, columns=counts.columns).round(1))

Output:

              not high  high

What this says in plain words. The chi-square statistic is 93.8 with 2 degrees of freedom, and the p-value is about 4e-21, far below 0.05. So we reject independence: income group and high internet use are related. All expected counts are above 5, so the test is valid.

Post hoc: which groups differ?

The test above covers all three groups at once, so it does not say which pairs differ. I ran the three pairwise comparisons (low vs middle, low vs high, middle vs high), each as its own 2 x 2 chi-square test without continuity correction. Running three tests raises the chance of a false positive, so I used a Bonferroni correction: the significance threshold becomes 0.05 / 3 = 0.0167 for each comparison.

# three pairwise 2x2 comparisons, Bonferroni: 0.05 / 3
pairs = list(combinations(["low", "middle", "high"], 2))
alpha_adj = 0.05 / len(pairs)
print("adjusted threshold:", round(alpha_adj, 4))
for a, b in pairs:
    t = counts.loc[[a, b]]
    c, pv, _, _ = stats.chi2_contingency(t, correction=False)
    print(f"{a} vs {b}: chi-square = {c:.2f}, p = {pv:.3g}, significant at adjusted level: {pv < alpha_adj}")

Output:

adjusted threshold: 0.0167
low vs middle: chi-square = 22.35, p = 2.27e-06, significant at adjusted level: True
low vs high: chi-square = 93.35, p = 4.38e-22, significant at adjusted level: True
middle vs high: chi-square = 36.45, p = 1.56e-09, significant at adjusted level: True

Interpretation. All three p-values are far below 0.0167, so every pair of income groups differs. Richer countries are more likely to have above-median internet use at each step: low to middle, and middle to high. The difference is largest between low and high income countries.

Limits. This shows an association, not a cause. The median split throws away detail in the internet-use rate, and the income groups are my own tertile cut points.
